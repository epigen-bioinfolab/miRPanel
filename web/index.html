How to read this page

  • Four different questions. Seed asks is there a canonical match. RNAhybrid asks could the duplex physically form. TargetScan asks how much repression, given the surroundings, and separately has evolution kept the site. miRTarBase asks did anyone test it. No single number can carry four answers.
  • Scores are never combined. Every column keeps its own units and its own arrow. −0.503 context++ and −18.5 kcal/mol are not comparable quantities, and averaging them would invent a number that means nothing.
  • A tight duplex is not evidence. RNAhybrid regularly gives a housekeeping gene a stronger ΔG than a validated target, because folding energy is all it measures and G:U wobbles count. Ranking by energy alone would put such a gene above the real one. That is the whole argument for keeping the columns apart.
  • Watch for one loud tool. A strong context++ with no conservation and no published test is a confident prediction from one method and silence from the other three — worth a second look, not a conclusion.
  • Four kinds of blank, never confused. — the tool ran and found nothing · not covered the tool cannot assess this — GAPDH's only sites are in the CDS and TargetScan reads 3′UTRs, so its silence there means nothing at all · not run the tool was not selected · not built it does not exist yet.
  • Positions come only from tools that measure them on your transcript. Seed and RNAhybrid read the MANE Select sequence directly. TargetScan scores a transcript it chose itself — different for 38.7% of genes — so its positions are not shown at all.
  • Region filters move the positional columns only. Switching off CDS hides seed sites and duplexes in the CDS — it does not change TargetScan or miRTarBase, which are gene-level and have no position to filter. Per-column filter popovers (score cut-offs, site-type sets, evidence tiers) stay in the Phase 7 specification; this toolbar is the minimum needed to read the page.
  • The four query shapes share this layout. Only one miRNA vs the transcriptome is running now. A gene-first or pair query changes which column is the axis, not what a column means — so the tool key, the empty states and the arrows all carry over unchanged.
  • Click a gene to open every record it produced, one row each, exactly as stored. The Agreement column is the one to read: ↔ contains 8mer seed site 1805–1812 means RNAhybrid's folded duplex covers the nucleotides your own seed tool matched. Two methods, written twenty years apart, landing on the same place without knowing about each other.
  • No score is turned into a word. The ΔG and context++ columns show the number and nothing else — deciding what counts as "strong" is the reader's call, not the tool's. The only threshold on this page is the −25 kcal/mol line used to colour the map, and it came from this run's own distribution, not a published standard.
